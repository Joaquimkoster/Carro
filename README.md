# Automotive Aerodynamics Visualization with NVIDIA Kit-CAE

Project developed using **NVIDIA Kit-CAE**, **NVIDIA Omniverse**, and **OpenUSD** to explore and visualize automotive aerodynamic simulation data.

The project focuses on scientific visualization of CFD data around a vehicle, including velocity fields, pressure distribution, streamlines, volumetric visualization, planar slices, and animated flow.

## Project Overview

The objective of this project was to learn how engineering simulation data can be imported, explored, and visualized inside NVIDIA Kit-CAE.

Using an automotive aerodynamic dataset, I created different representations of the airflow around the vehicle and explored how physical fields such as **velocity** and **pressure** can be transformed into interactive 3D visualizations.

The workflow included:

- Importing scientific simulation data
- Exploring CFD datasets and physical fields
- Working with vehicle and fluid-domain geometry
- Creating CAE visualization operators
- Visualizing velocity vectors
- Analyzing pressure distribution
- Creating and configuring streamlines
- Creating volumetric representations
- Using planar slices to inspect the flow field
- Applying scientific color mapping
- Controlling visualization through opacity
- Creating animated flow using NVIDIA Omniverse Flow
- Organizing the complete scene using OpenUSD

---

## Visualization Techniques

Several visualization techniques were explored during the project.

### Streamlines

Streamlines were generated from the velocity field using:

- `Velocity_0`
- `Velocity_1`
- `Velocity_2`

These components represent the velocity vector of the CFD simulation.

Seed regions were used to define where the streamlines originate, allowing different regions of the airflow around the vehicle to be explored.

Parameters such as step size, maximum steps, tolerance, direction, and streamline width were also adjusted.

### Velocity Magnitude

The three velocity components were combined using:

`vector_magnitude`

This produces a scalar representation of the total velocity magnitude, allowing airflow velocity to be represented through color mapping.

### Pressure Visualization

The `Pressure` field was used to visualize pressure variations around the vehicle.

This allows high- and low-pressure regions generated by the interaction between the airflow and vehicle geometry to be visually analyzed.

### Planar Slices

Planar slices were created through the CFD domain to inspect simulation fields at specific positions.

A horizontal slice was used to visualize the pressure field around the vehicle at approximately mid-body height.

### Volume Visualization

The CFD dataset was also converted into a volumetric representation using dataset voxelization.

This included working with parameters such as:

- Max Resolution
- Voxel Size
- Inflate Bounds
- Region of Interest
- Field Centering

This provided a volumetric view of the velocity field surrounding the vehicle.

## Color Mapping

Scientific values were converted into colors using Kit-CAE's color mapping system.

Different field-selection modes were explored:

- `unchanged`
- `vector_magnitude`
- `selected_component`

Lookup tables (LUTs) were also used to control the visual representation of simulation values.

Examples available in Kit-CAE include:

- `afmhot`
- `cividis`
- `gist_gray`
- `gist_rainbow`

Color domains were adjusted to highlight specific ranges of velocity and pressure.

---

## Field-Driven Opacity

Simulation fields were also used to control visualization opacity.

Velocity components were combined using `vector_magnitude` and mapped to opacity, allowing less relevant regions of the CFD domain to become transparent while preserving important flow structures.

This helps reduce visual noise when analyzing complex simulation datasets.

## NVIDIA Omniverse Flow

The project also explored **NVIDIA Omniverse Flow** for animated scientific visualization.

The workflow included:

1. Creating a Flow Environment
2. Creating a Fuel Injector
3. Creating a Dataset Injector
4. Mapping the CFD velocity components
5. Voxelizing the simulation dataset
6. Expanding the simulation region using Inflate Bounds
7. Running the visualization through the Omniverse timeline

This allowed the static CFD velocity field to be represented as an animated flow around the vehicle.

## AI Surrogate Simulation Data

As part of my studies with NVIDIA Kit-CAE, I also explored the workflow for visualizing simulation data produced by **AI surrogate models**.

Kit-CAE can visualize AI-generated scientific datasets containing fields such as:

- Velocity
- Pressure
- Turbulence

These datasets can be explored using workflows similar to traditional solver output.

This introduced me to how **AI surrogate models can be integrated with CFD visualization, NVIDIA Omniverse, and digital engineering workflows**.

## OpenUSD Scene

The complete project is organized as an **OpenUSD scene**.

The USD stage contains the original scientific dataset together with visualization operators, materials, shaders, Flow components, and other elements created during the analysis.

OpenUSD makes it possible to maintain multiple visualization methods within the same scene while preserving the original simulation data.
